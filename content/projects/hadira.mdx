## Overview

Hadira is the mobile client for a school attendance system. It integrates with the school attendance and internship (PKL) systems, and supports geolocation-based check-in, QR code scanning, and a parent dashboard that follows student activity.

## What the client handles

- **Geolocation and spoof detection.** Attendance is checked against the expected location and flagged when the device reports a fake position.
- **Parent dashboard.** Parents can follow daily learning activity and PKL progress from the same account.
- **Bilingual interface.** English and Indonesian copy are managed through localization so both language versions stay consistent.

## Challenge

The main layout issue appeared on Android 13 and above, where the app navigation controls overlapped the system navigation buttons. The fix needed to work across screen sizes and navigation modes, not just one device. Button placement and layout were adjusted so the app controls stay clear of the system navigation area.

## Notes

The project focused on the mobile client. Attendance data and school systems remain on the backend.

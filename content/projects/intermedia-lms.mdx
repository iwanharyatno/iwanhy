## Overview

Intermedia LMS is a learning management system for the organization's daily learning activities. It combines member registration, attendance, project submission, and grading in one workflow.

## What the system handles

- **Import and export.** Member accounts and attendance data can be imported and exported consistently.
- **One-click event registration.** Members register for learning events with an account that is already in the system.
- **Integrated attendance and grading.** Attendance, assignment scores, and pass or fail status are managed from one interface.

## Challenges

The delivery deadline was short, so the admin interface was built with Filament. It provided a dashboard-first structure that kept the focus on function, usability, and development speed instead of a custom admin layer.

The system runs on AWS EC2 free-tier compute. The deployment stays within the free-tier limits without extra infrastructure configuration.

## Stack

Laravel, Filament, MySQL, and AWS EC2.

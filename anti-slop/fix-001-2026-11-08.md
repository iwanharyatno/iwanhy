## What changed

- Replaced the cyan, glass, glow, gradient system with the `DESIGN.md` blueprint system: void `#0b1623`, surface `#101e2d`, accent `#ff9f30`, JetBrains Mono, 0px radius, visible 40px drafting grid, solid panels, 1px schematic borders.
- Added a shared layer for `SectionHeader`, `EmptyState`, `ProjectRow`, and `PostCard`, plus route-level `loading`, `error`, and `not-found` states.
- Rebuilt the home page as hero, asymmetric capability grid, alternating career timeline, zig-zag project rows, and a featured-note layout.
- Localized navigation labels, accessible names, loading and error copy, and portrait alt text.
- Removed the unverified metrics from the experience copy and the fabricated system-status footer.
- Removed `FloatingKey`, `TechBadge`, `framer-motion`, `lucide-react`, and `nextjs-toploader`.
